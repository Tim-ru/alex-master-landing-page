# Alex Master

Minimal Next.js project initialization for the washing machine repair website MVP.

## Stack

- Next.js App Router
- TypeScript
- ESLint
- Prettier
- Tailwind CSS

## Scripts

- `npm run dev` starts the local development server.
- `npm run lint` checks source files with ESLint.
- `npm run format:check` checks formatting with Prettier.
- `npm run build` creates a production build.

## Base Structure

- `src/app` contains the App Router entry points and global styles.
- `src/components/layout` contains the site frame, header, footer, containers, and sections.
- `src/components/ui` contains small reusable UI primitives.
- `src/content` contains typed content files for FAQ, reviews, symptoms, brands, and error codes.
- `src/lib` contains shared utilities and navigation configuration.
- `src/types` contains shared TypeScript types.
- `docs/stage-1-intake.md` records the goal, definition of done, and constraints for this initialization stage.
- `docs/stage-2-intake.md` records the goal, definition of done, and constraints for the UI scaffold stage.
- `docs/stage-3-intake.md` records the goal, definition of done, and constraints for the content model stage.
