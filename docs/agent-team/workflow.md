# Agent Team Workflow

## 1. Intake

Product Analyst или основной исполнитель фиксирует:

- цель задачи;
- ожидаемый результат;
- ограничения;
- критерии готовности;
- роль основного исполнителя.

## 2. Planning

Основной исполнитель определяет короткий план работы.

План должен отвечать на вопросы:

- какие файлы или области проекта будут затронуты;
- какие роли нужны дополнительно;
- какие проверки подтвердят готовность;
- какие риски есть у задачи.

## 3. Implementation

Основной исполнитель выполняет задачу и держит изменения в рамках цели.

Правила:

- не добавлять лишние возможности;
- не менять несвязанные части проекта;
- использовать существующие паттерны;
- обновлять документацию, если меняется поведение или процесс.

## 4. Verification

QA Tester, Code Reviewer или профильный агент проверяет результат.

Минимальная проверка:

- задача соответствует acceptance criteria;
- основной сценарий работает;
- нет очевидных регрессий;
- ошибки обработаны понятным образом;
- документация не противоречит реализации.

## 5. Handoff

Исполнитель передает результат с коротким описанием:

- что сделано;
- где находятся изменения;
- какие проверки выполнены;
- какие риски или ограничения остались.

## Definition of Done

Задача считается готовой, если:

- назначен и отработал основной исполнитель;
- результат соответствует цели;
- критичные сценарии проверены;
- найденные блокеры исправлены или явно зафиксированы;
- изменения можно поддерживать без знания скрытого контекста.
