# Agent Team Rules

Документы в этой папке описывают роли агентов в команде разработки и правило выбора исполнителя задачи.

Цель регламента: сделать работу агентов предсказуемой, разделить ответственность и не размывать владельца задачи.

## Документы

- [roles.md](roles.md) - роли агентов, зона ответственности и правила работы.
- [task-routing.md](task-routing.md) - правило, которое определяет, кто из команды выполняет задачу.
- [workflow.md](workflow.md) - общий порядок работы команды над задачей.

## Базовые принципы

1. У каждой задачи должен быть один основной исполнитель.
2. Остальные агенты подключаются как консультанты или проверяющие, если их роль нужна для качества результата.
3. Исполнитель отвечает за доведение задачи до проверяемого результата.
4. Ревьюер не должен быть основным исполнителем той же задачи.
5. Если задача затрагивает несколько областей, сначала назначается владелец результата, затем подключаются вспомогательные роли.
