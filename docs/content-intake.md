# Content Intake

Этот файл — анкета для мастера. Ответы напрямую заполняют поля контента сайта.
Заполни значения после `→` и передай разработчику.

## 1. Бизнес / контакты
> Файлы: `src/lib/constants.ts`, `src/lib/structured-data.ts`, `src/app/contacts/page.tsx`

```
PHONE_DISPLAY       → "+7 (921) 123-45-67"
PHONE_HREF          → "tel:+79211234567"
business.name       → "Alex Master"
business.city       → "Санкт-Петербург"
business.areaServed → "Санкт-Петербург и Ленинградская область"
business.hours      → "Ежедневно с 9:00 до 21:00"   # формат: "Mo-Su 09:00-21:00"
```

**Вопросы:**
- Как называть тебя/компанию на сайте (имя мастера или бренд)?
- Точный район работы (только СПб, или конкретные районы / вся Ленобласть)?
- Реальные часы работы, есть ли выходные?
- Выезд платный или бесплатный? При каком условии?
- Диагностика платная? Входит ли в стоимость ремонта?
- Гарантия на ремонт — есть? На сколько месяцев и на что именно?
- Принимаешь безнал?
