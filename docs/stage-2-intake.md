# Stage 2 Intake

## Goal

Create a basic UI scaffold for the MVP: root layout, header, footer, shared containers, sections, and small reusable UI primitives.

## Definition of Done

- The application has a reusable site shell.
- Header and footer are available from the root layout.
- Shared layout primitives are available for later pages.
- Basic UI primitives are present without pulling in extra dependencies.
- `npm run lint`, `npm run format:check`, and `npm run build` pass.

## Constraints

- Do not add full page templates from later stages.
- Do not add forms, validation, SEO implementation, analytics, or business integrations.
- Do not add UI libraries or dependencies before they are needed.
