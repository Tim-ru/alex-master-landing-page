# Stage 1 Intake

## Goal

Create a working Next.js project with TypeScript, ESLint, Prettier, Tailwind CSS, and a clear base directory structure.

## Definition of Done

- The project runs locally.
- `npm run lint` passes.
- `npm run build` passes.
- The directory structure is understandable and ready for later stages.
- Configuration files do not conflict with each other.

## Constraints

- Do not add features from later stages.
- Do not design UI, forms, SEO, analytics, or content ahead of time.
- Do not add libraries for future use.
- Do not add a separate backend, database, CMS, or complex architecture at MVP start.
